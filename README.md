# gen-z-roastmaster 💀

> Hall of Fame–tier Gen Z roast skill for Claude Code. Body someone with pure comedy using authentic Gen Z vocabulary, archetypes, and escalation mechanics.

---

## Install

**Option 1 — via npx:**
```bash
npx skills add antonio3471/gen-z-roastmaster
```

**Option 2 — manual clone (always works):**
```bash
git clone https://github.com/antonio3471/gen-z-roastmaster ~/.claude/skills/gen-z-roastmaster
```

Restart Claude Code after installing.

---

## Usage

```
/gen-z-roastmaster [name + info]
```

**Optional short alias** — create `~/.claude/commands/roast.md`:
```
Invoke the gen-z-roastmaster skill and roast the following: $ARGUMENTS
```
Then use `/roast [name + info]` directly.

> **Note:** name only = the skill asks for more info before firing. A roast without ammo is just noise 💀

---

## Examples

```
/roast john — works 14h/day on his startup, hasn't shipped in 6 months
/roast sarah — preaches minimalism, owns 400 plants and a Ring doorbell
/roast my professor — throws dice to pick who gets interrogated, 80% fail rate
```
